# Portafolio - Natalia Zárate Rojas

Portafolio web profesional que muestra proyectos, experiencia y habilidades en diseño de producto, UX/UI y diseño estratégico.

## 🚀 Características

- Diseño moderno y futurista con estética delicada
- Responsive design (móvil, tablet, desktop)
- Animaciones y micro-interacciones
- Carrusel de versiones con timeline interactivo
- Múltiples páginas de proyectos detallados
- Navegación fluida y experiencia de usuario optimizada

## 📦 Instalación

No requiere instalación. Solo clona el repositorio y abre `index.html` en tu navegador.

```bash
git clone https://github.com/TU_USUARIO/portafolio.git
cd portafolio
open index.html
```

## 🌐 Despliegue

### Netlify

1. Conecta tu repositorio de GitHub a Netlify
2. Configuración de build:
   - **Build command:** (dejar vacío)
   - **Publish directory:** `/` (raíz)
3. Click en "Deploy"

### Vercel

1. Importa el repositorio desde GitHub
2. Framework Preset: **Other**
3. Root Directory: `.`
4. Deploy

### GitHub Pages

1. Ve a Settings → Pages
2. Source: `main` branch
3. Folder: `/` (root)
4. Save

## 📝 Notas

- Todas las imágenes deben estar en la carpeta `assets/`
- Asegúrate de que las rutas de las imágenes sean correctas
- El proyecto no requiere servidor, funciona con archivos estáticos
